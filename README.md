# Portfólio — Orlando Pagnani Neto

Site pessoal construído com Vue 3 + Vite, apresentando projetos, stack e contato.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/data/projects.js` — lista de projetos exibidos na seção Projetos. Editar aqui para adicionar, remover ou atualizar um projeto.
- `src/components/` — seções da página (Hero, Sobre, Projetos, Contato) e a navegação.
- `src/style.css` — tokens de cor e tipografia usados em todo o site.
